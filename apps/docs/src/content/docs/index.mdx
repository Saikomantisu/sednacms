<CardGrid>
  <Card title="Forms from your fields" icon="pencil">

    to write posts, upload images, and publish content.
  </Card>
  <Card title="Publish without a rebuild" icon="rocket">
    Astro live collections read published entries from Postgres on demand.
    The next request can show an edit without a deployment.
  </Card>
  <Card title="Inside your Astro site" icon="astro">
    Install an integration and a server adapter. The admin, API, and public pages
    run in the same application.
  </Card>
  <Card title="Your database and storage" icon="database">
    Store content in Postgres and images in UploadThing or S3-compatible storage.
    If you enable CDN caching, publishing a change purges pages that read the collection.
  </Card>
</CardGrid>
